## probe.mjs change (clone-or-update step only)

Before: `<dataDir>\grimsheet` without `.git` -> mode fetch-reset was not chosen, but `git clone` into an existing non-empty folder would fail.
After: if `<dataDir>\grimsheet` exists without `.git`, the step deletes it (only if it is exactly <dataDir>\grimsheet), clones fresh, and records
  detail.mode = "clone-after-delete", detail.replaced = { reason: "folder without .git", entriesRemoved, removed }.
Nothing else in probe.mjs or ui\ was changed or rebuilt.
