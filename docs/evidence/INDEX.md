# Spike evidence index

## Redaction check (before any row is added)

1. Pass every text artefact (command output, reports, `_index.json`, snapshots) through the `scrub()` pattern from `spike/scripts/probe.mjs`. It replaces the value after the `token` query value, `Authorization:` and similar with `REDACTED`.
2. Search the scrubbed text for `token` (case-insensitive). Remove or redact every hit that holds a value.
3. For screenshots, check the page does not display the token before saving. Playwright captures the page, not the address bar.
4. Only then add the row and set `redaction checked` to `yes` (with the date).

The dashboard token URL from `kirocrew token` is never recorded: not in a file, a transcript command line, a screenshot or a file name.

## Naming

- Text and JSON evidence: `E<nn>-<slug>.txt` or `E<nn>-<slug>.json`.
- Screenshots: `E<nn>-<slug>.png`. `<nn>` is a two-digit counter; `<slug>` is a short lowercase description. No token text or URL in the name.

## Capture tool

The Playwright MCP server is listed in `.kiro/settings/mcp.json` as `playwright` (`cmd /c npx -y @playwright/mcp@0.0.84`, `disabled: false`, auto-approve: `browser_navigate`, `browser_take_screenshot`).
